# 证据型短视频的文字、数字与取景动效

在工程的画面脚本导入 scripts/kinetic.py。函数的 progress 为 0–1，由真实旁白时间轴计算。每一处动画绑定观众此刻需要发现的事实，例如划出落款或区分两个日期。把大动作安排在证据出现时，到达后留时间阅读。逐帧核对起势和落稳，原速检查是否和旁白中的关键词相遇。

| 画面任务 | 函数与取舍 |
| --- | --- |
| 口播说到一个新词时，只露出这个词 | masked_rise(canvas, text_rgba, (x,y), progress) 在终点字框内从下面揭示整组文字。用 RGBA 字层保留透明背景。紧接着有另一个词时错开入场，以固定名词作视线锚。 |
| 强调量级或规模 | count_to(0, value, progress) 先快后慢地生成显示数值。单位和数字基线保持固定，终值出现后停住并给出来源。计数过程只表现量级，阶段性真实数据使用各自的实测值。 |
| 展示某个时点已核实的签名量、人数或财务读数 | snapshot_number(canvas, layer, (x,y), text, font, progress) 按字符位置揭示已经排好的整个数值。把日期、样本范围和计量单位放在数字旁，结尾保留读数。有多个真实观测点时，分别展示各个点的数值与时间。 |
| 比较日期或两个有效状态 | digit_roll(canvas, (x,y), old, new, font, fill, progress) 保持两侧相同字符的位置，只将变化数字推出固定窗口。两字符串等长，位数不同可用空格右对齐。 |
| 从文件或照片进入细节 | evidence_zoom(source, output_size, overview_box, detail_box, progress) 取同宽高比的两个源像素区域，摄像机沿共享焦点推近。给观众看到文件出处，再停在能读清的证据行。 |
| 从一份实体材料换至另一份 | paper_reveal(outgoing, incoming, progress) 让固定纸纤维边穿过画面；两帧尺寸、模式相同。按话题使用，若有需跨镜保留的标题或署名，应在合成之后单独绘制它。 |

关键区驻留时避免用其他高反差元素抢眼。动效只拿来表达已经核实的事实。参考分析时分别记录可见的运动与自己的实现选择，例如看见逐帧累进数字，并不能确定作者用了怎样的曲线或软件。


例如，报道当日公开页面列出的签名数量时，把 `115,000` 先用同一字体完整画在透明 RGBA 层上。字层从数字左侧起排，日期和单位放到其余图层。传入该字层、数字原文和字体，再按选定时间段传入从 0 到 1 的进度。每一位沿各自窗口露出，千分位逗号、小数点和字形的相对位置沿用原排版。

```python
from PIL import Image, ImageDraw
from kinetic import snapshot_number

value = "115,000"
left, top, right, bottom = font.getbbox(value, anchor="lt")
layer = Image.new("RGBA", (right - min(left, 0) + 4, bottom + 5))
ImageDraw.Draw(layer).text((max(1, 1 - left), 1), value, font=font, fill=ink, anchor="lt")
snapshot_number(frame, layer, (x, y), value, font, progress)
```


## 让图层贴住实物

图层要跟随一块屏、纸或平面零件时，在源画面定位同一平面的左上、右上、右下、左下四角。逐帧渲染时把本帧的四角像素交给 `kinetic.pin_to_surface(frame, graphic_rgba, corners, foreground=matte)`。函数按透视将透明图层合入这一帧；可选的同尺寸灰度前景遮罩用白色保留盖在上面的手、线缆或纸边，用灰度羽化边缘。坐标和遮罩由制作人从原画跟踪或手工描出；发生剪切、失跟或物体离开时重新定位或撤下图层。

安排关键帧时，先找动起来前与停住后各应看到什么。解释图的指示线可在接近目标时减速；讲真实物体的速度或设备响应时按原记录保留加速、停顿和迟滞。文字标签落稳后再给读数，不让指示线、数值和镜头同时抢视线。讲解一段机制时，把定位、改变状态、停住读结果分开编排。在原件和示意之间保留同一物体的方向或轮廓。先原速检查动效是否让观众找到目标，再停在最难的遮挡与运动边缘查穿帮。颜色或亮度本身就是要比较的证据时，把说明放到旁边，保留原件表面的像素。

## 在普通镜头上逐层编排动作

`edit.json` 的每个镜头都可以写 `motion_layers`。例如实拍里一枚端子向右移动，先让标记跟到它的新位置，再在旁边补一层读数。脚本按数组由下往上把透明 PNG 叠到已匹配色彩的底片，随后在总片加品牌与节目字幕。想让物体经过字前面，可以把从该物体抠出的前景放在数组最后。

```json
{"motion_layers":[
  {"file":"assets/terminal-ring.png","width":0.12,"keys":[
    {"frame":4,"at":[0.36,0.49],"scale":0.88,"opacity":0},
    {"frame":10,"at":[0.39,0.48]},
    {"frame":21,"at":[0.58,0.48]}]},
  {"file":"assets/readout.png","width":0.19,"keys":[
    {"frame":22,"at":[0.70,0.42],"opacity":0},
    {"frame":28,"at":[0.70,0.39]}],"end":48}
]}
```

要原样使用这段参数，镜头至少需要 48 帧。`frame` 从本镜第 0 帧算起。`at` 为 PNG 支点相对整幅画面的横、纵坐标，默认支点在中心，`width` 为画幅宽度的比例，PNG 等比显示。坐标可在画外。每个关键帧可写正数 `scale` 和 0–1 的 `opacity`，缺省各取 1。默认每段先加速再减速，指定帧准确到位；需要中段停读，就在停留的首尾两帧给相同状态。第一关键帧之前隐藏；最后一帧后保持，写 `end` 则从该帧起移除。使用真实源余量做转场时，入点前的余量期间图层隐藏，出点后的余量延续末态（显式 `end` 会收起）。使用定格余量时，接缝沿用已经合成好的边界帧。

如果标注应跟着实际说出的词，可以把 PNG 关键帧的 `frame`、图层的 `end` 或 `layer_camera` 的 `frame` 写成词锚。例如台词 `check` 说“先看上限，再看当前值，最后回到上限”，下面的标注在第一次说“上限”时出现，在“当前值”时移动到第二个读数，在第二次说“上限”时退场。

```json
{"file":"assets/reading-arrow.png","width":0.12,"keys":[
  {"frame":"@check:上限","at":[0.36,0.48]},
  {"frame":"@check:当前值","at":[0.63,0.48]}
],"end":"@check:上限#2"}
```

同一镜可混用固定帧和词锚。`@check` 指整句开始，`@check:END` 指句末。图层退出可恰好落在镜尾。重录后运行 `prepare.py` 和 `export.py`，图层和署名随新词时钟更新。词头与画面听起来有偏差时，复听对应句，必要时填入已核对的 `word_times`。剪点跨句时，词锚仍取节目时钟，落点须在使用它的镜头内。关键帧合并到同一帧或顺序反转时，调整对应键或选择另一个词再导出。

### 连续穿过、绕轴转动与沿边缘揭示

要让镜头穿过中间构图或指示线跟住正在转动的零件，在图层上选 `curve`。除默认的 `ease`（缓入缓出）、`flow`（连续过键速度）和 `linear`（匀速）外，还支持 `ease_out`（快速入场平稳刹停）、`ease_in`（蓄力加速离场）和 `spring`（自然轻回弹，适合浮窗与徽章弹出）。各关键帧另支持 `blur`（高斯虚化半径，适合模拟焦外进焦与高速入场），图层可设 `"shadow": true` 自动投影增加与底片的空间层次。只需给镜头底片自身做亚像素推拉摇移时，直接在 shot 写 `camera` 或 `camera_drift`，详见[画质、转场、音画包装与节奏工艺](production-craft.md)。

下面是一根指针绕铰点旋转与一条纸面批注错开入场。整根针的透明 PNG 含铰点，`pivot` 用 PNG 内的归一化坐标表示；`at` 指定铰点在成片的位置。角度以度为单位、顺时针为正，按写下的数值连续变化。需要从 350° 再顺时针转 20°，下一键写 370°。每个键的 `rotation` 默认 0。

```json
{"motion_layers":[
  {"file":"assets/needle.png","width":0.24,"pivot":[0.12,0.5],"curve":"flow","keys":[
    {"frame":0,"at":[0.56,0.48],"rotation":-25},
    {"frame":12,"at":[0.56,0.48],"rotation":0},
    {"frame":28,"at":[0.56,0.48],"rotation":24}]},
  {"file":"assets/printed-note.png","width":0.22,"wipe":"right","keys":[
    {"frame":20,"at":[0.70,0.38],"reveal":0},
    {"frame":29,"at":[0.70,0.38],"reveal":1}]}
]}
```

`reveal` 取 0 到 1，表示沿 PNG 自身宽或高已揭出的比例，每键默认 1。`wipe` 为揭示边移动的方向，可填 `right`、`left`、`down` 或 `up`，默认向右。边缘随 PNG 一起移动和旋转，保留原件已有的透明轮廓。需要顺着一只手或不规则物体边缘换镜时，用[跟随平面与前景遮挡](#让图层贴住实物)的逐帧实物遮罩。动作承载事实时，用原片上的位置和时点排键。

从准备好的 `timeline.json` 读本镜帧数后再排关键帧；修改 `edit.json` 后重新 `prepare.py`、`export.py`。在导出片查标记是否盖住证据、字落稳后是否读得完、字幕是否与卡片相碰。如果物件速度或透视变化复杂，用本页的逐帧跟踪方案。PNG 使用带透明通道的单帧图像，保存为 sRGB 或内嵌有效 ICC，并在工程来源中登记原件。

制作表格、关系树、时间线、流程、终端行和柱图时，可用[让图表和真实口播一起变化](voice-cued-diagrams.md)中的组件按真实读数安排分层动作，并测量行内字形。
