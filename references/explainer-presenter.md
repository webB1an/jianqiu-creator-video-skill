# 口播怎样带出下一幅画面

先听人如何把一件事说明白。开场可以让主持人提出一个读者也会问的问题，随后切到能回答它的实物或原件。转折回到她的表情，结论再回到最初的东西。写稿时把相邻两句连着念：上句提出哪一个疑问，下句用哪个具体对象回答。数值带对象、日期、单位；一句塞进两种口径时拆开。提供了实际录音，就照说出来的内容核对字幕；书面数字、专名或翻译可用字幕写法，卡词用实际说法。

## 开机前把话和动作排在一起

如果能补拍，用可以连续录完一段的机位，拍到头顶、肩和做动作的双手。先录一次指向、转身或拿东西的动作，在准备挂图的那一侧留出墙面。试裁计划用的最近景，再检查眼神、手指和字能否同时入画。需要抠头发或眼镜时让人物与背景有明暗或色彩差。保留原声、句尾和自然的反应，给下一镜留出可以接住的动作。[原作者的主持拍摄与剪辑笔记](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/references/presenter.md)

有作者自己的口播稿时，沿用其称呼、习惯用词和表达判断的方式。试读时一口气说清一个动作，转折留给关键动词，需要观众读数时把解释缓一口气。下面是一个虚构的工单例子，四句连续念，换画面时保住同一条原声。

| 实际说的话 | 观众这时看哪里 |
| --- | --- |
| “这两张工单，怎么会是同一笔订单？” | 主持人先把问题说给镜头，两张原件在她身侧，大小足够看见各自的标题。 |
| “你看右上角的编号。” | 在“右上角”把第一张原件推近，给出完整编号和停读时间，主持人可以退到圆窗。 |
| “第二张的订单号也一样。再看下面，两张单上的排产号各不相同。” | 匹配切到第二份原件，对齐两处相同订单号。并排亮出两个不同的排产记录编号，让观众有时间核对。 |
| “原来这两次排产，接的都是同一笔订单。” | 保留原件，让两条排产记录连回已经核对的订单号，等结果读清再回到主持人收句。 |

反过来审一遍：只听声音能否说清“为什么是同一笔”，只看画面能否找到两个相同编号。若两句都在报观众已经读到的内容，删掉其中的重复，把时间还给看证据。[实测语速与留白](narration-pace.md)

## 按原来的声音剪

横版工程已有连续主持人录音或口播视频时，在 `edit.json` 顶层写 `presenter.recording`，逐句填写 `shots[].lines`。下面是一段虚构的示意，实际使用时换成原话和本片素材。

```json
{
  "presenter":{"recording":"sources/interview.mp4","room":"frames/room"},
  "shots":[{
    "id":"reading","visual":"generated/reading.mp4",
    "lines":[{"id":"question","text":"这次多了多少？"},{"id":"answer","text":"数值回到了起点。"}],
    "explainer_scene":{"scenes":[
      {"scene":"host","until":"@answer","says":"主持人提出问题"},
      {"scene":"number","value":"18","brow":"样本数","host":"pip","says":"标明这一组观察的样本数"}
    ]}
  ]
}
```

先运行 `prepare.py`。连续录音以原有呼吸、停顿和环境底声进入人声轨，只有节目最后不足整帧的部分补静音。换镜沿这条时钟切，画面从房间转入证据时嘴型继续向前。默认先从第零帧开始，后续镜头按其第一句实际开口的帧切。要提前给出证据、在句中切画或插入纯画面镜头，可在对应 shot 写节目绝对帧 `start_frame`，保留原录音和字幕时刻。画面独用主持人素材、声音已排在分轨里时，可直接指定下文的自备序列。

需要主持人出镜时，准备房间帧。命令在本期工程里运行，`PY` 和 `SK` 按运行说明设置。

```sh
"$PY" "$SK/scripts/prepare.py"
"$PY" "$SK/scripts/presenter_source.py" --project . --room frames/room
node "$SK/scripts/explainer_scene.cjs" --project . --shot reading --check
node "$SK/scripts/explainer_scene.cjs" --project . --shot reading
"$PY" "$SK/scripts/export.py"
```

房间帧以本片实际帧率对应原片时钟，`sequence.json` 留存帧数、帧率和来源摘要。跨多个 shot 使用整段同一目录，工具自动加上节目起始帧。换录音后重新准备，根据新录音抽新目录并调整配置。项目里本就有完整 JPG 帧序列时，指定 `room`、`frames`、与工程一致的 `fps`，帧文件从 `0001.jpg` 编号。用 `faceY`（在 1920×1080 画布上的纵坐标）修正圆窗的脸位。源图提前结束时指出缺失帧；只有编排上需要片尾定格时才写 `hold_last:true`。原声只需听而无人物画面时可省略 `room`。

手机变帧率原片按各帧实际显示时间取图。竖拍与非方形像素按原显示比例完整放入横版画布；HDR 原片先映射到 SDR，再形成浏览器合成所用的 sRGB 房间帧。源标记有误且已核准实际色彩时，用 `presenter.input_color` 覆盖对应的 `color_transfer`、`color_primaries`、`color_space` 或 `color_range`，重新准备和抽帧。场景切到竖窗时，回看皮肤明暗、头顶与手势的取景。

## 口型、词和图共用一个时刻

- 连续口播自动按实读词生成 `timeline.json → beats`。普通见秋配音或逐句自备录音可在 `edit.json` 顶层开启 `"word_clock":true`，给句子稳定、全片唯一的 `id`。例如 `@explain:利率#2` 是该句第二次提到利率，`@explain:END` 是句尾。一次开关、出数或切景都能引用它。临时录音换成正式录音后重跑准备和相应视觉生成器，词的绝对时刻随新录音重算。
- 本机优先用 SenseVoice 的音节起始时刻对照 `spoken` 或 `text`。按词分摊、字间插值和最后一字的结束均是估计。转写有歧义的字会列在 `estimated_indices`。专名、第二次出现的词、数字和句尾要回原音听。可以给连续录音提供 `presenter.word_times` 指向经听辨的 JSON，如 `[["利率",1.10,1.46],["回升",1.50,1.91]]`，用节目秒；逐句素材则在该 line 写同结构的 `word_times`，用句内秒。词序与实读一致，保留同音的人名正字。拟合程度太低时，回到原句补正后再定位。
- 画面上的百分号、缩写或中译字幕与原声读法不同时，`text` 写观众读的，`spoken` 写演员说的。普通工程仍可用 `caption_parts`、`caption_offsets` 精调字幕。有了连续口播，把 `caption_offsets` 设为距该句识别起点的秒数。
- 在见秋配音中插当事人原话，可在独立 line 写 `"source_audio":{"file":"sources/interview.mp4","in":12.20,"out":14.86}`，原声按源时钟单独抽出，和其它人声一起混音。需要唇形同步，在该镜使用同一文件、同一源入点，令实际发声时刻与画面对上（例如镜头从引文开始，设 `lead:0`、`in:12.20`）。前句交代谁在什么场合说话，截取时留足起音和词尾，原话结束后回到它回答的问题。已剪成整条连续口播时，先在原剪辑中确定插段和相应画面，再按连续录音导入。单独听开头辅音和尾音，再听前后两句的音量、空间差异；检查音画哈希和署名中的源入出点。正片审片报告的 `quote_levels` 实测引文与近邻解说的同版终混响度。足够长的片段比较 LUFS，短句比较同一口径的 RMS。确实太轻或太重时，给 `source_audio` 写 `gain_db`（如 3 或 -2），重新准备再听。

## 主持人该在哪里

| 观众正在做什么 | 画面和过渡 |
| --- | --- |
| 看表情、听她提出问题 | `scene:"host"` 用房间全屏。在转折词换取景，`zoom:[{"at":"@turn:但","s":1.12}]`；先在原画检查头顶与手势余量。 |
| 看她拿出一件证据 | 在 `host.items` 的 `at` 放照片、实拍或数卡。先看现场墙面和主光，安排在头肩一侧；把逐帧人物透明层放到物件上方，头发自然遮住照片一角。一件已说完时用 `out` 收走。 |
| 记住决定性的一个词 | `swap:{"at":"@turn:利率","words":["利","率"]}` 在同一动作上替换远景和夹层文字，人物保留真实位置。 |
| 需要同时观察图和人的解释 | 在图形场景用 `host:"window"` 做侧边竖窗，左边图板保留阅读宽度。需要读全屏原件时用 `host:"pip"`，连续几个证据镜可共用一个圆窗。原字在窗下时换构图。 |
| 场上同一张图要变成实际发生的事 | 墙卡写 `fill:{"clip":"machine","d":0.5}`，下一场 `footage` 接同一源段已经播放到的时间。大画面可独立停留，下一场再让圆窗回到画面。 |
| 要回到提出问题的人 | `host` 的 `enter:"grow"` 将圆窗或竖窗长回房间；`enter:"drop"` 让已经读过的图板退下，露出同一时刻的人。在同一 `explainer_scene.scenes` 镜头组内连接这些变形。 |

墙卡和换背景需要 `presenter.cut` 指向与房间 JPG **相同尺寸、帧率、首帧、数量**的全画布透明 PNG 和 `box.json`。本机的[主体抠像与边缘处理](wallstreet-craft.md)可制作这组素材。只用原房间、圆窗或侧窗时可以直接裁取原片。人物出镜的比例随人物表现和证据的阅读量定。主持人离场时仍可听到完整原句。回到房间前看原镜头手势是否连续，也要检查人物回来的第一帧有没有压住关键字幕。
