# 一段画面怎样动，观众才看得进去

剪粗剪时先问「观众上一秒看哪里，下一秒要认出什么」。在本期时间线上找一组具体的答案，把时间给第一次发生的事。动作、图层、剪点和声音可以在不同帧交接。

## 从原素材剪出动作

- 实拍先找动作开始前、接触或转向、结果稳定的连续原段，记下原声和可借用的前后余量。全景交代空间，近景要补上全景里看不见的变化。优先选有明确光向、主体轮廓和前后景分离的原件。在预计的最大裁切处按成片尺寸看纹理、焦点、压缩边缘和运动拖影，再决定能推进多远。
- 一张照片也能提供两个镜头。先给出观众能认出原件的全貌，再把视线交给能改变判断的局部。需要空间感时，从有清晰遮挡边界的素材分出前、中、后景，按同一镜位设置近处较大、远处较小的位移；先看行程两端是否露出补画缝。文字、直线和人脸经过边缘最容易看出变形。标签贴着移动平面时按[逐帧贴合与遮挡](kinetic-evidence.md#让图层贴住实物)处理。
- 录屏保留触发动作、界面响应和可读的结果。档案用原页和局部建立出处。人物镜头里一次停手或一次抬眼就能交接注意力。场景已有足够运动时，把包装的幅度收小，给表情、手势或原声留位置。

## 把不同的运动交给不同帧

| 现场有什么条件 | 具体剪法 | 回看哪几帧 |
| --- | --- | --- |
| 前后镜有共同的物件或形状 | 旧画面缩成下一场的一格，或让文件框移到新背景中的相同位置。主体离场时让下一层从原处接住，字幕保留自己的基线。 | 动前一帧、两层同时可见的一帧、旧层完全离场、新物件首次可认。遮住字幕仍应能跟住同一对象。 |
| 有多个例子、分屏或解释节点 | 先立可读的主体，再让连线抵达目标、标签出现、下一分支进入。已经解释的窗格可继续播放，固定边框、标签和组别颜色。用 [PNG 图层关键帧](kinetic-evidence.md) 分别排期。 | 逐帧找首个可读的名词与第二个入场。若两种运动同时争夺中心，可先收一边的对比度、延后第二次入场或减小位移。 |
| 章节或层级真的发生变化 | 顺着刚看过的方向拉开，露出它在整个空间里的位置，再进入下一对象。实拍可沿物理遮挡换景，短促方向模糊只占移动最快的一段。 | 看切点两侧的方向、速度、目标屏幕坐标；在运动终点检查字边清晰、无跳位、抠像白边或背景露洞。做一份直接切的版本比较。 |
| 需要观众读一条结论或看清反应 | 让高亮顺原文展开、让辅助信息淡退，或把已成立的答案留在同一位置作对照。让观众看到落点后再换字幕，结论读完仍有动作时可保留安静的背景运动。 | 量首次可辨、停稳和被下一层遮挡的帧；以目标播放宽度从前镜连续读一次。数字日期用真实端点，计数动画的中间数要符合其表达的含义。 |

构图先定落点，再向前推起势。快速入场可把主要位移放在中段，接近落点时逐帧减小步幅。慢移保留浮点坐标，最后一次采样再落像素。实拍物体由原速度和惯性决定剪点。位移、缩放、透明度、遮挡和焦点承担不同任务；能靠一个动作交代的变化，可以把其余层当作稳定参照。

旋转照片时，起点和终点满幅，中间角度仍可能露出三角黑边。计划满幅就沿完整运动路径逐帧检查四角覆盖，留足裁切余量；需要让人看懂「把照片转正」时，可把完整相纸与四条边一同摆进画面，转正后才推到照片内。把最斜的一帧与字幕、角标一起查看，纸边经过的位置也要给两者留空间。

例如，一支约 24 fps 的引文片中，F443 旧提示框仍完整，F444 原帖叠入，F445 标题出现，F449 原帖单独可读，F450 才开始下一句字幕。另一处向上换场，在 256×144 缩图里，提示框顶边 F202–204 的纵坐标依次为 72、63、46，临近落点的 F210–212 则为 9、8、7。做自己的原件揭示时，可以分别控制底板、标题和字幕的到达时间，并用相邻帧的位置差检查减速是否可见。帧数随新素材的行程、目标帧率和实际句长重排。

## 让一个对象带观众走过几刀

做财经、科技或产品解释时，先找一个能贯穿这段的实物、数值或原句。分镜上写清楚上一镜最后在看什么、下一镜去哪里找它。例如讲设备耗电，可以先在电表上看见实测值，把这个值留在固定位置，底下换成每个实际工作环节的画面，再沿其中一个画框推入对应部件。每次换实拍要补充一个能认出的环节。换了统计口径、单位或工况时，一并换掉旧读数。

- 一串实拍共同解释一个名词或数值时，用[跨镜固定图层](picture-edit.md#把同一对象留在换镜前后)。让对象单独占据可读的位置，选材时预留这块空间。需要从其中一个对象展开讲，先保留两者同时可见的一拍，再用[双源取景](motion-frameworks.md#双源取景)把选中的实拍窗口推满，接到同一动作、同一取景。没有需要追踪的对象时，可以直接硬切。
- 需要在同一张关系图或同一组实物之间换重心时，用下方分层机位。把下一处证据预先放在画面空间里，机位移动时让远景略移、近物经过得更快。与当前对象相关的标注最后才亮起。观众要核对文字或数值时，让该层停稳；包装和字幕各守一个阅读位置。
- 原文变为分析图时，先让人看见出处和原句，再交给图中的数值。把两侧的对象、单位和时间范围逐一对应。仅有终值时可展示终值与来源；有逐期观测值时才画时间序列。需要交代差多少时，用[共用刻度的两项比较](jianqiu.md#让两项实数和它们的差依次出现)。在声音上，把方向变化留给轻短的移位声，把较重的一下留给真正的接触或结果落定；已经清楚的实拍动作可直接用现场声。

参考的无人出镜片段中，8.4–8.8 秒金额收成片名上方的小字，10.4–13.0 秒底下换机房与工地画面。26.0 秒出现报道全貌，26.6 秒进入标题，约 26.8–28.0 秒刷出重点并停读，随后原件退后、图表进前。时间来自公开 GIF 的连续显示帧（每帧 0.2 秒）；两帧之间更细的动作可对照项目场景代码。拟音取舍参考其制作说明。[原作 GIF](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/examples/ai-burn-money/sample.gif) · [对应场景代码](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/examples/ai-burn-money/film_lib.js#L195-L230) · [声音设计说明](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/references/audio.md#L33-L40)

### 用一个机位移动多层图像

横版 `edit.json` 的 shot 可以写 `layer_camera`。以下例子中，空间里原本就有两张物件图，机位从全貌移到右边的卡扣，远处标尺只移动一部分。底片 `visual` 始终铺在这些 PNG 下面；需随镜头移动的背景细节用一张有余量的 PNG 放在图层列表最前面。示例至少需要 43 帧。

```json
{
  "layer_camera": [
    {"frame":0, "look_at":[0.5,0.5], "zoom":1},
    {"frame":24,"look_at":[0.66,0.47],"zoom":1.14},
    {"frame":42,"look_at":[0.69,0.47],"zoom":1.19}
  ],
  "motion_layers": [
    {"file":"assets/ruler.png","width":0.66,"depth":0.35,"keys":[{"frame":0,"at":[0.5,0.52]}]},
    {"file":"assets/latch.png","width":0.28,"depth":1,"keys":[{"frame":0,"at":[0.69,0.47]}]}
  ]
}
```

`look_at` 是目标平面上的画幅比例坐标，`zoom` 是该平面的倍率。物件的 `at` 和 `width` 表示机位移动前的位置和尺寸。默认 `depth:1` 跟随完整机位；0 到 1 之间的值产生较小的位移和缩放；`depth:0` 固定在屏幕上，仍可用该层自己的关键帧移动。贴在同一物件上的字和线使用相同深度。机位在同方向中间键保持连续速度，两个相同的机位键可以留出停读。放大时确认素材细节足够，在首帧、位移最快处和末帧检查透明边缘是否露缝。[原作的分层机位](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/scripts/stage25d.js)

## 把镜长、声音和字幕排在同一条时间线上

先通读整条时间线，把每段改写成「观众已经知道什么 → 这段让他多看懂什么」。给第一个能改变判断的原件留位置，让接下来的操作回答它引出的疑问，片尾回到开头的同一对象展示实际变化。若连续两段都只能写出同一条答案，把较清楚的动作提前，删去重复解说，把省下的时长交给最难看懂的一步。已有首次观看记录时，把观众第一次复述正确和第一次想跳过的位置对回段首 `section`，直接修改本期脚本和剪点。片长由实际故事决定。

1. 给段首写一个观众正在做的事，例如「找问题」「追动作」「读结果」。在分镜相应的 cut 填 `section`。排原素材时，先选一镜承接上一问，再剪几次更短的动作推进，最后把时间还给首次可验证的结果。人物口述可以让一条原话跨镜，到表情发生变化才换景。按本片信息量调整这段走势。
2. 在关键镜对齐**动作发生、结果可认、声音落点、字幕换句**四个时刻。`motion_layers` 和 `watch` 用镜内帧，`cue_frame` 和 `motion_windows` 用全片帧。把同一画面中最先该看到的动作排在前面，第二层回应；有些回应值得提前听见，有些应在结果可读后才响。读完结果前，暂停下一轮滚动、数字翻牌和标题入场。
3. 环境声可以跨切点把两镜接起来。接触帧用有材质的短拟音；揭示前可撤一层音乐，结果落稳后才让乐句进入。旁白给专名、数值和词尾留出空间。带人声原速听，再用[同响度 A/B 与手机频带试听](screen-and-mix-review.md)查哪一层遮了词、哪一下增加了位置感。持续柔和的镜头也可以只留原环境声。
4. 先用[源色彩匹配](output-color.md)把相邻素材的曝光、白平衡、黑位和肤色接好，再定整段基调。选择一帧作邻镜对照，最亮处看文字和高光有无丢细节，最暗处看主体能否分开。可让场景色温在转折时改变，读数、证物颜色和图例保持可信。包装用一个稳定的强调色和固定字位，轮到谁解释才给谁亮度或动势。
5. 正片导出后用 `review.py` 对照[分段节奏](picture-edit.md)和观察窗。连着几刀都等长时，听它们是否在重复同一个重音。揭示段字幕密、读数窗口又短时，先删重复口播，或从已交代过的镜头借帧给结果。关掉旁白看视线接得上，恢复总混以 1 倍速看观众有没有时间理解。逐帧检查边缘和先后，最终速度由原速看片决定。
