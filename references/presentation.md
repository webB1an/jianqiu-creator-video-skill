# 观众点开 MP4 的前五秒

正片或可独立观看的重剪，把本期选定的人声、同期声、配乐或动作音混入同一文件。人物口述、听辨演示可以只用授权原话和现场录音。单项实验可以只交对应声部或画面。交观看版时，从最终容器复核实际使用的各部分。

**开场的画面任务。** 画面承担开场信息时，遮住字幕、静音，以正常速度看前五秒。声音承担核心信息时，先连画带声听完第一句或第一个声音事件，再静音看画面是否交代了场所或声源。逐次指出观众看清的对象、动作和第一次得到的新信息。真人动手、视线转移、原件入画、数字从总量转向子集都可以成立。一次很轻的推拉、背景漂动、角标或字幕更新可能造成帧差，却不能说明观众学到了什么。争议转场回看连续原帧，留意转场上边缘切出残句以及正在移动的数字会不会碰到下一行，重点信息落稳后留出读完的时间。

参考片《我们做了个特别的键盘》里，人物到来信到高亮段落让人逐步发现选题的由来。影视飓风的镜头分享中，主持人同一机位拿起不同对象也能推进；给每支片定死每几秒必切会剪坏这种动作。先问观众看到什么，再考虑加第几刀。[何同学原片](https://www.youtube.com/watch?v=tPAnFz01ieY) · [影视飓风原片](https://www.youtube.com/watch?v=FWcdMFoaYyk)

**浮动字幕。** 正常导出和 `render_window.py` 共用 `floating_captions.py`。标准 SRT 按实际入出帧叠加，字后圆角按实际字形和行数排版，短句自动收窄。缺省 `caption_style: "plate"`；希望深底画面只保留轮廓时用 `"outline"`。画面从头到尾铺满画幅。取景时把原文中需要读的字段放在字幕之外，避免日志、正文与字幕连成一句。用手机宽度复查最短和最长句、最亮和最暗镜头，两侧背景须连续。横竖构图分别确定安全边距。

普通字幕默认靠下。已用 `evidence_read.readback.roi` 框住的原文或读数，在该镜 `watch` 的整个停读区间会自动让字幕和可调度的人物身份条避开。其他需要保护的对象在对应镜头填 `caption_avoid`。将读数、人脸、身份条、出处等值得保护的区域各写一项，`box` 依次为该交付画幅内归一化的左、上、右、下边，`frames` 为镜内半开帧区间，省略时覆盖整镜。运动中的对象可按位置变化分成几个区间。

```json
{"id":"meter","caption_avoid":[
  {"label":"压力与单位","frames":[16,34],"box":[0.25,0.82,0.74,0.98]},
  {"label":"人物身份条","frames":[0,15],"box":[0.08,0.63,0.48,0.82]}
]}
```

本地人物身份条可指定[允许的出场窗口、时长和占位框](remotion-library.md#把身份条排在证据读完后的空档)，它会沿用这份保护区排到连续空档，横版字幕自动读取排定的身份条占位。其他包装先按台词和内容排出场时机。可以晚出的身份条或出处，放到读数停稳、观众读完之后，再为实际出场段填占位。程序用最终 SRT 的字块大小逐时段检查字幕与占位是否相交，并为整句择位，连读时跨过剪点也可保持位置。上下两处均有冲突时会列出帧号和对象，调整包装时点、换行或构图后复查。需人工定位置时，在对应镜头填 `"caption_position":"top"` 或 `"bottom"`，其优先级高于该镜的自动避让，位置按指定剪点生效。带内嵌定位或样式的 SRT 沿用作者排版。重新准备工程后，整片、局部返修和普通字幕的画面探测沿用同一份 SRT 和时间轴。给下方探测命令加 `--project .` 可验证实际位置。

**声音按约定验。** `edit.json` 的 `audio_intent` 填期望的 `["music","effects"]`，与实际的 `music`、`effects` 分轨独立。常规配乐与动作音口播片可沿用这两项默认值。只有单独现场声轨时写 `["effects"]` 并将这轨登记为 effects。全部现场声已含在审核过的采访录音、没有另外叠轨时写 `[]`。按本期创作选择事先填好。有预混的特制项目也要在登记候选时写下期望，避免漏传某轨后审片一起跳过。将导出的 AAC 与复听过的总混比对；直拷 AAC 可逐包确认，另一编码须在匹配时序、音量和编码条件下另验。分开核对片头乐句和具体操作帧，至少保留一份与旧版同节目响度的可播 A/B。已约定另有配乐或动作音，却只用人声就能重建最终所有音频包时，把漏混直接退回。总混能量和手机频带近似各有观测范围；主观音色与设备外放须实际听辨。

```sh
python "$SK/scripts/presentation_probe.py" "$MEDIA" --clean work/clean.mp4 --srt audio/captions.srt --out qa/presentation
```

预编码总混以流拷贝入片时，运行 `python "$SK/scripts/confirm_mix.py" "$MEDIA" --approved-audio sound/mix.m4a` 验包内容、时点、声道和裁样。也可传 `--voice-only` 与同一编码条件的干旁白做反证；干声对照不同只说明未逐包复现，仍须用同期声部和听审判断可辨度。

画面探测会输出前五秒时码图、避开字幕区域的连续帧差、以及匹配干净底片时每个字幕中点的可见改动范围。机位保持不变仍可能有重要的细微动作；压缩噪声和底图颜色会影响数值。首看席 `opening_picture / muted_replay` 写 `subject, visible_change, reading_hold`，从第 0 帧检查。字幕席 `caption_overlay / encoded_frame` 写 `subject, phrase, surrounding_picture, box_fraction`，边界顺序为归一化的左、上、右、下。声音及连续运动沿用[终混与运动复核](screen-and-mix-review.md)。
