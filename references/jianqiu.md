# 见秋的固定制作规格

完整昵称「一叶见秋起」，口播、角标和评论中可自称「见秋」。片头直接展示观众点击时想看的对象或结果。署名放在角标和收束镜头。给用户原始素材设计内容时，要保持照片里的历史对象、人物和产品身份准确。

**图卡共用一套字和颜色。** [品牌配置](../assets/brand/style.json)保存名字、字体和色板。[identity.py](../scripts/identity.py) 提供字形与颜色，并生成可缩放的 leaf.svg、头像 avatar.png 和透明署名 signature.png。中文标题用简体宋体粗字，说明用简体黑体，数值和拉丁单位用 Avenir Next。传入「30 帧/秒」之类的混排时，整行使用同款中文黑体。按实际文字量排版，先量字宽再定坐标。换行时数字、小数点和单位留在一起。

```python
from identity import card_colors, card_face

colors = card_colors("light")  # 深底图卡用 "dark"
value = "2.56 MB"
draw.text((96, 120), value, font=card_face("metric", 80, value), fill=colors["accent"], anchor="lt")
```

图卡画布用 `background`，标题和主要文字用 `text`，必要的条件与单位可用 `muted`。用 `accent` 指向本镜要看的值。确有第二组比较对象才用 `compare`，同时写明组名或使用不同线型。浅底自带深琥珀、深青绿。程序画卡可取 `title / label / metric` 三种字体。实拍、网页原件和产品状态保留自身色义。字幕由共用合成器排在原画上，图卡、原件和字幕各自保留阅读空间。选取亮暗极端帧与最长字幕，缩到手机宽度看标题、单位和原文能否读清。[浮动字幕与检查方法](presentation.md)

**同一对象跨镜头、画幅和封面沿用同一色义。** 单镜点题可用一次强调色。颜色一旦用来区分对象，就在本期 `edit.json` 里登记，例如 `"comparison_roles":{"quiet":"compare","boost":"accent"}`。图表改成竖排、证据换边或两组互换出场顺序时仍按对象 ID 取色。已有两组色义时，用括线、停顿或位置引导当前视线。对白字幕保持中性。原始截图的报警红、地图图例与设备灯色照原件呈现。

- 项目生成折线、条形或标签时，调用 `comparison_color(edit["comparison_roles"], "quiet", "light")`，得到相应浅底色。深底写 `"dark"`。可选角色有 `accent`、`compare`、`text` 和 `muted`。同时写组名，必要时配实线和虚线。
- [双源证据镜头](motion-frameworks.md#双源取景)可给某个源写 `"legend":{"text":"静音模式","entity":"quiet"}`。参数文件默认读取同目录的 `edit.json`，另设 `"edit":"../edit.json"` 可复用整个项目的定义。只写 `text` 时生成中性标签，省略 `legend` 时保留干净画面。本地渲染与 Remotion 共用标签字形。开头两组能读清，转向全屏时收去已经放不下的标签。
- 封面若需给对象上色，在 `cover.json` 写 `"line_entities":{"静音模式":"quiet","性能模式":"boost"}`。三个画幅按实际标题行的完整文字查找对象。重排不改变色义，另写过的一行标题可明确指定新文字对应的 ID。验收时将首屏、揭示帧、回切帧与三版封面放在一起，核对同一名称和数值的归属。

**画面与封面。** 正片固定横屏 16:9。默认采用 1920×1080 原生画布。主镜头先安排主体、视线和光线，再决定信息层级。优先给到实物特写、看得清的变化和连续动作。时间、编号和英文只在有识别作用的位置出现。比较镜头保持坐标和比例一致。导出时自动加「见秋」角标，同时制作 1920×1080、1080×1920、1080×1440 三张封面。为每集写 cover.json。用 image 选无字幕的主图，focus 是原图主体的相对坐标，lines 是封面短标题，kicker 可选。layouts 可为 16x9、9x16、3x4 分别设置 subject_at、photo_width（照片显示宽度与画布宽度之比）和 lines。缺配置时从第一镜生成草案，交付前必须检查缩略图、主体边缘和标题可读性。观察主体、构图、节奏变化时用帧和时间码，真实点击率需要发布后的数据。

**人声与节奏。** 需要合成解说的新片采用本地 ZipVoice「见秋」男声，新做的新闻和科技、财经、产品解释片的常规句从 1.22 倍试读，需听清数值、单位或定向读音的句子从 1.16 倍试读；人物与档案叙事可从声线设置 1.04 起读。按[口播与镜头节奏](narration-pace.md)对比真实录音的句长与可辨度，人名、数字和关键揭示可单独安排重音与停顿。先删重复句，再压缩衔接。按题材兑现标题的承诺。实测可在开头直接呈现冲突，口述可以从原话与环境声进入，档案可以先留下值得辨认的一处细节。用实测「汉字数÷有字幕的语音区间」比较新旧语速，它是估算值。看不清图表时延长画面停留；词音模糊时给该句放慢或改写。不要把所有镜头平均切成同样的秒数。

**音效入库。** 先按动作、材质、空间和时长查本地 assets/sfx。需要新音源时，执行 python scripts/soundbank.py search "camera shutter"，根据匹配度筛选，再比较评分、评分人数与下载量。高分少票只作候选。详情页没有评分时如实保留空值。遇到 Freesound 搜索限流，search 自动查询 Openverse；返回 openverse_id。核对作者原页的 CC0 条款后可在 add 命令加 --openverse-id ID 使用索引的公开试听链接，索引不提供的评分维持空值。选定后用 python scripts/soundbank.py add shutter <Freesound声音页面> 入库。本工具验证页面声明为 CC0，保存该页面公开提供的 HQ MP3 预览、48kHz 工作 WAV、作者、当日评分与哈希。试听预览不是上传者的无损母带。其他来源（包括 Pixabay）按其实际许可使用，下载次数和星级分别记录。来源限制单独再分发时不打入可迁移包。每次用过的录音直接留在库里，定期复用，不重复下载。

**对画面落声。** 在项目根目录写 sfx.json，元素含 shot、key（库中名称）、trim（源音频截取起止秒）、anchor（录音中所选瞬态的秒）、peak_db、pan、event。用 at 指定实际口播词或原片动作帧，需提前或延后时加 shift_frames，也可沿用距镜头起点的 offset 秒数。将文件路径写入 edit.sfx_plan，重录后正式导出会重新落声；独立运行 soundmix.py 可生成 audio/effects.wav 与 qa/sound-cues.json 试听。普通实拍可用 location_sound 让现场声跨切点延续。[词锚、动作帧与同期声写法](screen-and-mix-review.md#用重读词和动作接触帧定位声音)。把用到的资产快照放进项目 assets/sfx 可离线重建。音效用于实体动作或有意义的交接；讲解需要专注的地方留静。独立听人声、拟音，再核对终混响度、单声道听辨和字幕。声音库浏览入口为 assets/sfx/catalog.html。

## 让两项实数和它们的差依次出现

当问题是「两项实测相差多少」时，让两条横条从同一个零点伸出，先给一个值，再给第二个值。等两端都落稳，沿它们之间的距离画括线，显示绝对差。这样在手机上扫一眼能看出谁更长，继续留在同一画面就能读出差多少。比金额先对齐币种、时间范围和统计口径；比百分比时，两个读数都用百分数填写，差值自动用百分点。只知道一方的值时，另一方用文字交代已知范围，另选原件或单数镜头。

把下面的字段放到本期 `edit.json` 对应的 shot。示例是虚构的耗时，制作时从本期证据填写测量值、条件和单位，并在工程来源中记录原件。给生成图单独的工程内 `visual` 路径。工具会标记生成镜头，返修同一镜号时可原位重建。在项目的 `comparison_roles` 中设置 `{"cold":"compare","warm":"accent"}`，或省略每行的 `entity` 使用中性字色。

```json
{
  "visual": "generated/latency.mp4",
  "value_comparison": {
    "title": "同一任务的完成时间", "unit": "秒",
    "rows": [
      {"label": "首次运行", "entity": "cold", "value": 14.8, "reveal": [0, 12]},
      {"label": "重复运行", "entity": "warm", "value": 8.6, "reveal": [14, 26]}
    ],
    "gap": [29, 42]
  }
}
```

在项目完成 `prepare.py` 后，以实际镜号运行 `"$PY" "$SK/scripts/value_comparison.py" --project . --shot latency`，再正常导出。两组 `reveal` 和 `gap` 是本镜从零计的起势帧、落稳帧，示例最后一个动作在 F42 完成，之后的镜长都可用来读结果。每次改数、改节拍或改对象色再生成该镜。默认深底，可在 `value_comparison` 设 `"surface":"light"`。两把量尺共用真实零点，支持正数、负数和零。数字显示原始端值，末帧保留两组名称、单位和差值。成片字幕放在下方时与数图错开。
