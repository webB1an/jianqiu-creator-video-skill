# 关联元素的视觉对齐

**先确定共用的轴。** 角标的方块和文字共享竖直中线。紧凑图注的底板随字宽变化，检查四边留白。票据两栏可保持左、右对齐，分别让标签和金额组合落在本行的竖直中线。数字与单位可共用基线，再以整组可见范围定位。开关两端应将状态文字放在滑钮以外的可用区；让素材自身的偏心构图保留在外层版面。

使用 Pillow 绘制时可复用 `scripts/optical_layout.py`。用实际字形的可见边缘定位。英文、数字、中文混排或字号变化时，字体的 ascender 与固定字符框会带来不同的上方留白。动画中让同一关系共享运动参数，检查进入、切换状态和停稳时字底有没有忽然上跳。

**从实际画面登记。** 普通候选把每个 cut 送交版式席。先提交覆盖这一镜的 `frame_inventory`，写明看到的主体、依据、回放状态和 `components`。同时看嵌在素材里的标签牌、数值组、自制图卡与原件。外层叠字轨为空的实拍、拼接画幅、已扁平化的 PNG 都可能包含这些对象。纯摄影镜头可填 `components: []`。制作时在 screen-plan.json 的 cut 里用 `alignment_components` 预列，审片时补入实际看到的对象。其他设计关系仍可用 `alignment_groups` 命名。

| 对象 | 制作时 | 编码画面上量什么 |
| --- | --- | --- |
| 镜头内标签牌 | `draw_ink_plate` 用真实字宽和对称内边距生成紧凑底板。需要固定宽度左对齐时用 `draw_ink` 向左锚定，垂直仍取字形中心。 | 每块底板单独取内部区域和可见字形。固定左对齐板用 `axis: "y"`，居中牌用 `"xy"`。半透明板要从本层边缘判定上下留白。 |
| 混排数字、单位 | `draw_bottom_runs` 让不同字号使用同一个可见字底，组内可各用独立字重和颜色。 | 用数字、单位各自的可见框，设 `relation: "bottom", axis: "y"`。比较两个 y 下沿，得到单位比数字高低多少像素。 |
| 自制内嵌表格 | 用 `editable_row_boxes` 按本地实际分隔线切出行区；有线宽时取笔画内侧，末行延至本卡内容底边。各列文字在本行字形中线上绘制。 | 逐行量。若同一行有独立绘制的左右列，用 `cells` 分别量两组文字与该行。卡内排版随嵌图统一变换到最终画幅坐标；逐行保留现场边界。 |
| 原文、图像证据 | 用 `source_image` 标明出版物、截图或任务原件。素材上另行叠加的底板、标注或自制译表分别登记。 | 保留原件像素，核对外部取景、标注和可读性。原文在镜内切换成自制卡时，分别登记两种状态。 |

例如，镜头先给档案原件，然后同位置展示解释表。可使用以下组件表同时供分镜与实际清点。从实际画面另外发现标签时，把该牌加入清点结果。

```json
[
  {"kind":"source_image","id":"document","source":"招股书原页"},
  {"kind":"label_plate","id":"archive-credit","axis":"y"},
  {"kind":"number_unit","id":"distance"},
  {"kind":"editable_card","id":"terms","rows":[
    {"id":"demand","cells":["label","value"]},
    {"id":"commitment","cells":["label","value"]}
  ]}
]
```

这会要求 `archive-credit`、`distance`、`terms/demand/label`、`terms/demand/value`、`terms/commitment/label`、`terms/commitment/value` 的测量。单行只有一组文字时可以用行名字符串。静态表或依次展开、最后同屏的表使用默认的 `display: "together"`。全部行和单元格至少共享一个实际停稳帧，各自另取一个可见状态。共同帧上，比较不同数据行的局部上下边界，同一行各列可以共享纵坐标。

同一位置在不同时段轮换内容的图卡，用 `display: "sequence"`，并在每一行写 `visible: [镜内首帧, 镜内结束帧]`，包含首帧，结束帧属于下一状态。各替换时段互不重叠；每项测量取自该行实际可见的时段，同一行有多列时仍共享至少一帧。分镜预检和成片审查都读取这个布局，采样时的帧号使用成片绝对帧。

**量实际导出的候选。** 取原分辨率解码帧，把画面缩到手机宽度，再看各组是否协调。审片人从同一候选记录一帧停稳和另一帧可见状态，随观察说明回放时看到的运动关系。用字实际占用的半开像素边界记录 `ink_box`。用对应格、容器、图标或同组另一对象记录 `reference_box`。两框可沿另一轴相离，例如方块在字的左侧。以 `axis` 选择应同心的轴，使用 `xy` 时两轴都核对。共底的数字和单位以数字为参照、单位为被测对象，单独校验底边。

在正常 `observe` 或 `supplement` 的一条观察内填 `perception`。下面的数字只演示字段，实际坐标从当次 MP4 读取。

```json
{
  "shot": "switch", "start_frame": 40, "end_frame": 65,
  "evidence": "手机宽度回放，状态字与滑钮保持各自空间。",
  "perception": {
    "kind": "alignment", "method": "encoded_geometry", "group": "switch-on",
    "subject": "开字与滑钮左侧可用区", "axis": "xy",
    "samples": [
      {"frame": 53, "ink_box": [122,96,158,134], "reference_box": [79,73,202,157]},
      {"frame": 62, "ink_box": [128,96,164,134], "reference_box": [79,73,213,157]}
    ],
    "playback": "滑钮到右端后，字在左侧落稳，转场前留白相近。"
  }
}
```

签发工具校验组、帧窗、像素范围和中线偏移。容差取 1 像素、按画幅短边折算的 2.5/1080、两对象较小轴长的 3.5% 中的最大值。小字因此保留抗锯齿与压缩余量。超差的观察加 `issue_id` 并提交匹配的退改票，主编在修订候选复查。几何通过后仍以实际阅读感觉和连续播放决定是否需要调整。测量只覆盖所列关系，审片人同时检查计划遗漏的文字、边缘或动画状态。

对未提供镜头计划的自定义工程，审片时查看整个候选，逐镜补记录可辨的关联元素。遇到纯实拍，或仅展示单一物件、没有需要对齐的图文组合，可用 `alignment / frame_inventory`，填写 `subject`、`basis` 和 `playback`，覆盖待审的完整区间。已具名的组必须有对应的实际边界。已签发的历史文件仍可校验。对旧文件重新开审，发布目录只有影片和凭据时，从凭据的 `rhythm_cuts` 恢复切点，以这份影片的实际总帧数封闭末镜。同目录的时间线通过凭据 SHA-256 核对后才用于复原。

## 三类静帧回测

导航相机的原尺寸图层上，上牌字形顶部留白 20 px、底部 37 px，下牌分别为 13 px 和 23 px。地图的距离数字可见下沿是 764 px，单位是 776 px。合同解释卡按分隔线内侧核对时，上行两格中心分别高 29.5、30.5 px，下行分别高 38、38.5 px。外侧来源栏与整页卡片均可居中，而这些局部关系仍可失准。

运行 `"$PY" "$SK/scripts/replay_inset_layout.py"`，用这七组原尺寸测量值回放旧偏差，再以修正静态布局校验每块牌、数字及单位、四个单元格。还会检验漏列单元格、伪用整卡边界以及原件保持不动。

## 网约车片漏检复盘

《打车点特惠，司机能不接吗？》第二轮，观众席看了第 53 帧，量的是画面底部的口播字幕。票面虽然同框，席位报告只确认三个数字能读清。声音席在首轮回看第 226 帧，核的是滑钮变为「开」时的拟音。事实席对读了司机经历、金额和南京条文。会审中唯一的返修票是把「抽成」补成「抽成比例」。主编关闭这张票后签发，前两轮均没有人提交票面文字相对分栏中线、状态字相对滑钮可用区的判断。

用户反馈后，在同一旧候选的第 58 和 68 帧量到「这一趟的流水」字形中心高于所在栏中线 38 像素。当时的手机观看和字幕抽查都可以如实通过。漏检发生在审片分工和主编取证两处：排版没有明确负责人，主编也没有要求能回答这个问题的证据。旧片已有缺陷的画面在第二轮局改范围之外，逐帧比对自然仍会相同。

下次遇到一张带字幕的票据，观众席检查字幕可读性，版式负责人另指出票面的标题、金额各属于哪一格，在实际编码画面上量对应的轴。遇到开关则分别看「开」和「关」在滑钮旁的可用区域。主编将每个结论与它的证据配对；若无对应记录，交回负责席位补看。出现新的漏检，用同版旧画面重跑新增检查，确认能指出用户看到的问题，再用修订画面验证改法。

复核审片工具或移植 skill 时，运行 `"$PY" "$SK/scripts/replay_fare_row.py"`（`SK` 为 skill 根目录）。[回测脚本](../scripts/replay_fare_row.py)读取包内第 58、68 帧的原尺寸票面裁图，用现行审片校验分别检查缺少证据、旧片偏移和修订通过三种结果。
