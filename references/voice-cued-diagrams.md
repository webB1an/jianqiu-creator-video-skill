# 让图表和真实口播一起变化

科技与财经解释片把每一张表拆成可单独运动的对象。先用本版配音生成的 SRT 定位每项事实，再把标签、连线、端点和数值各自的动作落在附近。数字和单位作为同一层入画。源文件修改过台词或换了语速，重新从字幕提取提示帧。

`scripts/voice_diagram.py` 可以单独导入。它处理口播提示帧、按折线实际长度描线、当前步骤居中、日期按日历定位、带正负值的共零点柱和可见字形居中。在技能运行环境以 `python scripts/voice_diagram.py --sample /临时目录/diagram-check` 生成六个真实状态与像素收据。样例数值仅供核验部件。

## 按语义拆图

| 镜头任务 | 入画与后续动作 | 落稳时核查 |
| --- | --- | --- |
| 表格与发行资金 | 出现的横线、标签与金额分别定时。说到“钱归谁”时将该行连到收款人，同屏背景行保留不同的款项归属。 | 一条金额只对应一个标签和一类股东。以本行上、下分隔线的中点为共同视觉轴。 |
| 治理或关系树 | 中心框按字形居中。每个分支从根部，经公共折点走到端点，圆点、标签和条款在到达时相继出现。 | 对根框做双轴测量；同一分支的线端与文字组处在同一横轴。某项权利到后一句才解释，另给该数值一个提示帧。 |
| 公司时间线 | 用真实日期定点，先显示第一项，让当前时间在轴上推进至下一日期。当期研究目标放在该日期下作注释。 | 在 `date_positions` 输入年月或完整日期。不能把无日期的研究目标当作一个年代。 |
| 连续步骤 | 说到的步骤占中心。下一步进入时，前一步移动至左侧。工具循环或两项争用同一容量时，将已出现项收拢，画出回路或汇合路径。 | 每个步骤的标题、说明与图标共同行动。排查前一步过早抢占当前读数或新项突然出现在停点。 |
| 模型档位或终端行 | 色条、箭头和单双行文字按同一行可见中线放置。具体例子出现后点亮对应档位，并在同一行接出任务名。终端可逐字写一般说明，数量和单位整组出现。 | 英文字体、中文字体分别量墨迹。字幕靠近切点时，给末尾的完整单位留出能读清的真实帧数。 |
| 柱图与后半段解释 | 标签先入位，柱从公共零点伸出，数值贴着端点落稳。讲完三种单价进入返工问题时，把柱缩成可回看的小尺，让算术示例或验收公式占据视觉中心。 | 同一时刻同一数值共用一把尺。画面初始已有完整句、公式刚出现就切走、后三分之二只有小脚注变化，都要重新分配信息与停留。 |

## 在项目动画里接入

```python
from voice_diagram import local_captions, cue, arrival, ease, bar_end, ink_group

captions = local_captions('audio/captions.srt', start_frame, shot_frames, fps)
anchor = cue(captions, '输出十万')
window = arrival(anchor, shot_frames, advance=10, settle=1, hold=12)
progress = ease(shot_frame, window)
zero, tip = bar_end(value, 0, largest_value, chart_left, chart_right, progress)
bounds = ink_group(frame, (label_left, row_top, label_right, row_bottom),
                   [(model_name, model_face, ink)], align='center')
```

`ink_group` 将两行的实际字形先组成一块，再让整块与色条、箭头或行区共用中心。返回的 `ink_box` 与 `reference_box` 可用于镜头样片检查。正式验收应从带字幕的交付候选再取同位置的解码帧。多行需要更大的内容区时应重排。代码会报出越界文字。

流程图可用 `step_positions(总数, 各项到达比例, 视口中心, 两项间距, 入场附加距离)` 获取每项中心。累计三个状态 `[1,1,0]` 时第二项在中心，第一项左移一个间距。树图用 `branch_parts` 取得分支折线、描线、圆点和标签四项，再让 `path_stroke` 依照实际路径长度画到指定位置。

将看得到的变化从局部画面与整张图两个尺度一起抽样。口播仍提供新判断，图表却已经数秒只保留同一页时，优先考虑把下一条证据、算术步骤或因果关系做成新动作。观众正在对照原文或数字时，保留阅读时间。审片后再决定哪些停留有据可留。
