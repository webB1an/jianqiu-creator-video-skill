# 读完原件再换空间

横版正片在镜头调色、单镜图层合成之后制作这里的动作。字幕、品牌和跨镜固定图层在拼接之后叠加。把换空间的那一下留给有前因后果的地方。例如，读完原文的数值，再看对应图表，或点到电路图上的某个引脚，再看它的实测波形。

## 原件倒成桌面，图表从前景立起

在下一镜写 `"transition":{"name":"desk-rise","seconds":0.7}`。先安排上一镜留足读原句的时间。进入转场后，原件上方远边往下退，两侧形成透视，页面减暗成为桌面。下一镜稍晚从下方升起，达到全画幅后继续按原时间线播放。图表应把第一次需要看清的读数排在立稳之后。前一镜是新闻原件、后一镜是该原件支持的统计图时，两者沿用同一对象、单位与日期范围。

## 沿指定物件推穿接下一镜

在后镜的 shot 中写入下面的字段。示例的目标在画面偏右上方。

```json
{"transition":{"name":"push-through","seconds":0.4,"at":[0.73,0.38],"zoom":2.4,"handles":"source"}}
```

`at` 是上一镜**最终取景**中的点，横、纵比例都从左上角算。该点在放大的过程中留在原位置，周围图像加速经过、虚化退出，下面的实拍接手。查上一镜最后一次可认的物件中心，下一镜最好能很快找到同一物件或它的结果。同一画框里的素材要扩大到满屏并原速续播时可用[双源取景](motion-frameworks.md#双源取景)。

## 更多原生空间与光学桥

除 `desk-rise` 和 `push-through`（支持可选 `settle` 让入镜从轻微放大平稳落稳）外，同一转场入口现还提供：

- **`whip-left` / `whip-right` / `whip-up` / `whip-down`**：五次缓动 + 峰值方向运动模糊，起止两帧保持清晰，适合同级证据快切。
- **`blur-dissolve`**：光学离焦叠化，上镜柔和虚化、下镜由虚入实，适合时空或视角跨度较大的切换。
- **`dip-ink` / `dip-paper`**：经见秋深墨 `#131A17` 或米纸 `#F4EDDD` 短暂停顿换章，给大段落留出呼吸。
- **`pull-back`**：从锚点 `at` 拉远退入更宽语境（参数同 `push-through`，支持 `zoom` 与 `settle`），与推穿互为呼应。
- **`iris-open`**：从指定锚点 `at` 平滑张开柔边圆形光窗露出下一镜。

两个转场及上述全部空间桥都跨在原有切点两侧。`seconds` 四舍五入为项目帧数，前段取整除二、剩余帧给后段。首个过渡帧完整交给旧镜，最后一个完整交给新镜。`handles:"source"` 借用上一镜实际后续与下一镜实际前序，适合移动原件；默认 `hold` 用边界帧补齐借出的区间。具体源帧数、剪点和区间载于 `technical.json → transitions`。镜内关键帧按各镜自身帧号安排。原声、字幕和整段长度沿用原时间轴。

## 从画中节点展开证据窗再收回

在需要弹窗的 shot 上设置 `evidence_window`。底片 `visual` 连续播放，窗内素材有自己的源入点。这个例子在 30 fps 下先让背景运行八帧，再由电路图右边的节点放大一个独立波形窗口，看完后回到同一节点。

```json
{
  "id":"board",
  "visual":"assets/circuit-board.mp4",
  "evidence_window":{
    "file":"assets/measurement-detail.mp4","in":1.2,
    "from":[0.73,0.36,0.055,0.08],"to":[0.17,0.13,0.66,0.62],
    "open":[8,20],"close":[66,78],"dim":0.64
  },
  "lines":[]
}
```

合入已排好时长的 shot，示例要求本镜至少 79 帧。只有这个无台词镜头时可用 `tail` 安排停留。两个矩形按 [左、上、宽、高] 填最终画幅比例。`open` 表示从完全隐藏到展开到位的本镜帧，`close` 表示从开始收回到完全隐藏的本镜帧；中间留给阅读。运动过程中卡片可随节点外形改变比例，到位时用等比留边显示完整原件。`dim` 设定停读时底片的相对亮度，1 保留原亮度。输入可以是视频或照片。视频从 `in` 对应的源秒开始播放，照片省略 `in`。现场录音单独放入本片混音。成片的帧窗、原件路径和源入点列在 `technical.json → evidence_windows`，选中的库内证据同主画面一起登记署名。

从原件首次可认处查找图表第一次能读的位置。对推穿，回看目标中心和切换后的视线；对窗口，看满幅截图的边界、细小原字、背景回亮的时刻，以及下一步操作有没有被遮住。相机还在运动时，用节点在开窗和收窗时的真实屏幕位置设计构图；同一固定窗适合两次交接落在同一处的画面。方法源于参考库在无人出镜片中安排的纸面、资金节点和实拍交接。[制作示例与场景代码](https://github.com/HeyChengC/wallstreet-explainer/blob/f39845abd45dab3c9ce62587aa5d02f6afe82612/examples/ai-burn-money/film_lib.js#L300-L353)
