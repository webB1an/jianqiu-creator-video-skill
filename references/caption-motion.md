# 短字幕、参考片与连续动作

prepare.py 保留整句旁白的语调，把显示文字按逗号、顿号、分号、句号或问号分别上屏并去掉分句标点。无标点长句用中文分词，优先控制在 14 个全角字宽以内。日期、数字和缩写保留必要的内部符号。需要指定语义停顿时，在 line 增加 caption_parts，例如 ["董事会接受辞呈","当天生效"]，对应 text 为“董事会接受辞呈，当天生效。”。默认依据当前录音和附近低能量位置估算句中分界。在同一句里，自动字幕不足 0.45 秒且合并后仍能在一行读完时，会并入相邻词组并保留外侧时码。“原尺寸”“采样率”等术语整词显示。指定 caption_parts 或 caption_offsets 的字幕沿用作者的分段和时间。无法合并或由作者指定的短闪在 prepare 时打印镜头、时长和文字，便于粗剪时复核。连续录音中的数字读法、人名或快句可提供 caption_offsets，例如 [1.42]，秒数从这条录音的开头算。审片看 qa/content-check.json 的 joined_clauses、overlong、short_flashes，结合回译和句意调整。短句回译对同音人名和数字容易误判；启用 --asr 时，低匹配片段还会留下整镜回译。人名依然含混可重写前后文、降低该句语速或提供已确认的录音。纯外语单词超长时手工安排字幕。

分析参考片的动画和转场，按[全帧索引、连续帧图与原速声画窗口](story-sound.md#带时间码拆片)操作。字幕另看四帧：旧句最后可读、新动作触发、第一处证据可认、新句首次可读。若新句把注意力从动作上拉走，试着错开两者的入场，或让旧句跨过剪点。正常语速听一遍，保住字幕与说话的关系。

**同一对象跨镜**。让文件签、标注线或主体留在观众视线里，新背景从其后方进场。用 scripts/motion.py 的 progress/pose 从两镜共享的绝对帧区间求坐标，切点两边共用一个对象的绘制函数。**解释关系**时可用 branch() 从起点沿曲线描线，在端点附近淡入对应信息，最后留出阅读时间。此类已经绘制好两侧动作的镜头使用 cut，保留原有轨迹。对独立拍摄的素材需要画面桥时，在进场 shot 写 transition 为 page、glide、focus 或 {"name":"page","seconds":0.45}。文字层做叠化时，让旧标题先退、新标题后进，同时保留一件连续移动的对象。转场时长在原剪点两侧分摊，字幕、拟音和节目总长保持对齐。根据动作和阅读方向选用，正常直切依然可用。

收到具体审片反馈后，在当期片中修复。能跨选题复用的规则写回 skill，能运行的动画、字幕逻辑或授权音效放进 scripts 或 assets。用新主题或隔离片段重跑，观察字幕和剪点，再更新已交付的可迁移包。人物姓名、报道事实和这一期的配乐编排留在项目。

本机 SenseVoice 可用时，先 `prepare.py`，再运行 `scripts/sync_captions.py`，它会从实际口播音频中定位词的起点，写入 qa/caption-alignment.json。核对识别中的专名和数字，再加 `--write` 保存有足够匹配、段长可读的句内边界，已指定的时码会保留，最后重新 prepare。数字读音与展示不同、自动分段不同步时可为该行添加 spoken_parts，数量和实际字幕段一一对应。未对齐的句子保留原来的分段或用实听给出 caption_offsets。
