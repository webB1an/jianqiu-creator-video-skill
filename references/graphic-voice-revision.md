# 按讲话节奏返修解释片

接到截图或一句错读，先在已交付 MP4 找到相应字幕和前后镜头。记录时间、字幕、要看的对象或要听的字。再检查同一渲染器生成的其他镜头、同一读音在全稿的其他上下文。返修前保留旧片和旧字幕，返修后用各自版本的字幕定位同一个词。重录改变了后文时间码时，使用新的采样时钟重新合画面、音乐和字幕。

## 给观众一个可跟随的动作

| 所讲内容 | 制作时如何安排 |
| --- | --- |
| 报价或数量变化 | 逐位滚动并在口播目标值处落稳，小数点与单位固定。中间过渡值用滚轮形态表示，屏幕保留足够时间读取最终值。开场分屏可让另一侧播放与该事件有关的实际动作，角标写清来源和拍摄年份。 |
| 人物履历 | 从一手现场或访谈选能辨认人物和动作的连续片段，逐位对应姓名与职务。涉及两个年代时在画内标明素材年代。履历按身份、前后职位或时间揭示。 |
| 条形、金额或份额 | 从共同零点绘出长度，标签随末端移动并停靠。金额、范围和单位保持同一口径。第二个比较出现后可以补上差额、费用构成或条件；回到口播中真正需要这个动作的词。 |
| 时间线、资金路径或组织结构 | 日期落点后推进游标或镜头，触达节点才展开对应事件。关系图先给主体，再沿路径描线，随到达顺序亮起端点和结果。 |
| 连续步骤 | 当前步骤优先放在主阅读区；讲下一步时前一项向一侧让位、下一项到中心，结尾留足读完结果的时间。对同时比较的表格，可以保留共同基线并移动焦点。 |
| 表格、短标签与命令窗口 | 按真实字形墨迹计算水平和垂直位置。行在上下分隔线之间定中线，字段再各自取内容框，考虑箭头、图标、内边距和数字单位。用混排的实际字形测试。 |
| 转场 | 在上个镜头找可交接的东西，例如金额行、纸边、画面中的取景窗。选接缝两侧检查指向、位移和新信息初次完整可读的帧。证据需要立即辨认时直接切。 |

视线的运动方向由材料关系决定。连续几镜都从上往下露出字时，回到各镜实际任务，分别选择沿线移动、同位比对、放大证据、逐字输入或移交焦点。观看时应当能指出每个动作解释了哪句话。

## 地图、轨迹与片尾分屏

路线图先找可信的起终点、途经点和读图方向。地图先留一个可认的地貌作参照，按口播分别沿规划线和实际线推进标记，到转弯或偏离处停一下，让观众看出两条线何时分开。可在保留署名的原图上加沿线移动的定位点，用 `voice_diagram.path_stroke` 按折线弧长绘制摘出的对照线。已有公开路线静图时，根据原图可核实的像素位置描线，保留颜色对应、走向和形状；方向不明时改按地标逐处比较。取景推到局部之后，稳定地貌再推进轨迹。观看完成后应能指出这趟行程哪一段相同、哪一处不同。

只有全程总距离时，把数字和单位放在终点揭示。可以让起终点合拢到距离括线、把已描完的曲线交给总里程、或让目的地标注切到稳定的最终数字。只有原始数据提供了分段里程或真实读数才按这些数据依次计量。镜头的节奏来自观众认出路线、到达终点、读到结果这三步，避免在真实地图上制造逐秒里程表。

片尾回到开场的数值时，先写明它现在与第二条事实有什么关系。资金可以由总额拆成两笔，跨度可以由起止年份实际拉开，再交给一句可检验的结论。右窗讲设备、电源、工作现场时，先查库、再核对原片的主体、真实动作和使用依据。存在相符且有使用依据的片段时，用连续源帧取出动作起势到结果的区间，登记原片入出秒及裁切，检查右窗在左窗读数期间仍能看到什么。此物件只有静态原件，或需要持续对读固定铭牌时，登记静图、理由和读图停留时间。两侧分别安排动作或阅读任务，一个区域的像素变化只能说明该区域。

## 在编码片中复查

在 screen-plan.json 的 cut 下可以标记观察区。roi 是左、上、右、下占画面宽高的比例，时间沿用该 cut 的起止帧。尽量圈住人、图形或原文，并避开字幕与角标。

```json
{"motion_probe":{"roi":[0.54,0.17,0.93,0.75],"subject":"右侧开市现场的人物和手势"}}
```

含并列证据的新分镜使用 `motion_probes`，每一项对应一件可单独复述的动作。例如地图可分别登记稳定地貌、沿原线推进的标记和终点读数；片尾分别登记左侧数值和右侧素材。选与本镜相关的区域。下面两个片段是不同 cut 的可选字段；帧段取镜内相对帧，结束帧不含。画面坐标须从本片实际构图取得。

```json
{"motion_probes":[
  {"region":"route","mode":"trace","subject":"实走轮迹","roi":[0.17,0.37,0.50,0.72],"reference_roi":[0.08,0.48,0.13,0.59],"span":[30,102],"action":"固定相邻山脊，定位点沿橙线经过弯道，最后抵达终点"},
  {"region":"distance","mode":"readout","subject":"里程与单位","roi":[0.68,0.54,0.88,0.72],"span":[90,137],"action":"终点括线接到总里程，数字和米同时落稳"}
]}
```

```json
{"motion_probes":[
  {"region":"amount","mode":"readout","subject":"左侧金额","roi":[0.09,0.39,0.46,0.71],"action":"从发行价过渡到合同期限与最低采购额，保留计量单位"},
  {"region":"rack","mode":"footage","subject":"右侧设备","roi":[0.62,0.16,0.93,0.71],"source":{"file":"assets/rack.mp4","in":4.5,"out":9.6},"action":"原片中手转过把手，托盘随之抽出"}
]}
```

`change` 适合其他可见变化。`still` 对应有意保留静图的窗口，例如 `"source":{"file":"assets/plate.jpg","reason":"让观众读清铭牌两行额定参数"}`，其 `action` 仍要交代读哪处。原片署名及授权记录按素材清单保存。

分镜阶段可先填预计使用的素材。冻结候选包时，`footage` 的本地原件按工程目录解析，逐帧解码指定入出点，核对所选区间是否完整覆盖且含多个视频帧。原件的 SHA-256、字节数、容器、视频编码、画幅、时间基准、解码帧数和首尾实际显示时间随区域写入 `bundle.json` 的 `source_verification`。本地原件不可解码、实际只有一帧或时间超界时需修正素材或入出点。只有外链、素材尚未到位或是引用外部切片的清单时，包内保留待核状态 `pending` 及原因，成片审查标记 `source_not_verified`。补齐可核对的本地原件后重新冻结。原件通过后仍要从成片窗口对照原片核实动作和署名。

导出会把每个窗口独立固化在候选包里。单独封装且未提供时间线时，可在 `footage_source_checks` 查看已声明实拍的来源核验结果。随时间线封装时，窗口受成片及时间线哈希约束，review.py 从成片以每秒 8 次取样，在 content-check.json 的 component_motion 各行保留区域、动作、原件与入出点。旧工程的单个 `motion_probe` 和无标记图形仍按原口径检查。active_share 是有可见像素变化的相邻样本占比，longest_quiet_seconds 是最长的样本变化间隔。四秒以上的长停留或指定动态区域内没有可见变化会提示复查；有意静图保留实际测量值和理由。

路线或数值的 `looks_like_dissolve` 表示采到的中间图像近似首尾两态透明叠加。`surroundings_move_with_subject` 表示附近本应固定的参照和主体在同一批样本中一起变化，常见于整张底图的推移。它们都是看片线索。回到同一候选的起点、中间、落稳帧，先固定附近地物看标记相对它走到何处，再看数字是否在对应语句到来时落到正确值。动态素材要另对照原件同一动作前后帧，核对主体和标注。每个区域独立记录原速观看到的状态；背景光效、角标、字幕或其他窗口活动不能签发这一项。短于一个采样间隔的动作按原视频帧率定位。

数图从纵排重组为横排时，应沿整段移动检查模型名、数值与相邻柱形的轨迹。可以让文字在旧位置淡出，柱形单独移位，停稳后在新位置重显。用原速和关键区间的连续帧复查交叉点，保留数值与对象的对应关系。

版式审片从最终 MP4 取进入中、落稳、退出中的实际帧。圈出容器和文字墨迹，分别量左右或上下留白。表格列的刻意靠左排版按同一列的阅读线评估，行内垂直位置仍按行中心核对。金额旁的小单位还应检查共同基线。仅检查“在框内”和看静态底图都会漏掉偏心与运动中相撞的问题。

中文配音先把高风险词放回整句确认意思，写明期望读音和声调。相同汉字的不同读法分别处理。检查模型实际采用的读音，合成后听上下文，再从最终混音截取这个词和下一句。句尾还要检查声母、韵母、衰减和后一句起点。识别器能转出正确汉字、字幕完整、音频时长匹配，三者均可能与误读或尾音不完整同时发生。必要时换完整载句重录，在停顿中切，保留尾音和间隔，再重锁后续镜头的时间。

准备口播时可在单句里填写 pronunciation 的词组、音素、载句和验收用的尾字。运行 prepare.py 后用实际合成文件和终混复核。字段与命令见[中文配音与词组定向读音](voicecasting.md)。制作金额、步骤和分支图时，可用[按话音驱动图形](voice-cued-diagrams.md)里的 voice_diagram.py 实作字幕锚点、日期轴、路径描线、居中卡片与数值阅读时间，也可从[财经、科技和产品解释镜头](explainer-scenes.md)选择与口播对应的组件。
