# 从横屏正片另剪 9:16

选了竖屏信息流，且原画里的字、手或对照组在窄屏里会丢失时，回到原件逐镜重排。两张实验图在手机并排太小，可以让它们占用同一块位置，固定源坐标、倍率和色彩处理，按证据出现的顺序原位切换。需要辨认手与设备的位置时，先给完整动作再进局部。根据发布预览给字幕和关键数字各留一块可读区域。

沿用横版剪点和终混时，为每个镜头准备无字幕的 9:16 图片或片段，按下面的字段写一份计划。相对路径从计划文件所在的目录起算。每项从 `start_frame` 起，到下项的起点或原片结尾为止；视频素材从其第一帧按原速使用。多余的片头在编排该镜时预先剪掉。字幕可将同一条 SRT 重新换行，起止跟原口播对齐。只有竖版重写旁白或改变时长时，才另编竖版时间线和终混。

```json
{
  "master": "../out/final.mp4",
  "captions": "../out/captions.srt",
  "size": [1080, 1920],
  "captions_px": [66, 900, 1490, 50],
  "shots": [
    {"start_frame": 0, "visual": "手与面板.mp4"},
    {"start_frame": 72, "visual": "按键反馈.png"}
  ]
}
```

`captions_px` 依次是画布上字幕区的左边、右边、下边及字号，可按平台界面实测改动。运行 `python scripts/portrait_cut.py 本期/vertical/plan.json --out 本期/vertical/portrait.mp4`。脚本共用见秋浮动字幕，按母版帧数封装画面并拷贝其原音轨。每个输入镜头都要是已经编排好的正方形像素 9:16 画面。竖版属于独立候选，交付前在实际观看宽度核对切点前后的同一主体、可读信息和遮挡，记录本次看的是缩小的导出文件、设备本机，还是平台转码稿。
